# 🤖 AI Attendance System Using Face Recognition

An AI-based attendance system built using Python, OpenCV, and Face Recognition.

This project automatically detects and recognizes faces through a webcam and marks attendance in a CSV file with the current time.

---

# 🚀 Features

✅ Real-time face detection  
✅ AI face recognition  
✅ Automatic attendance marking  
✅ Webcam integration  
✅ CSV attendance storage  
✅ Multiple face support  
✅ Beginner-friendly AI project  

---

# 🛠 Technologies Used

- Python
- OpenCV
- face_recognition
- NumPy
- CSV
- Datetime
